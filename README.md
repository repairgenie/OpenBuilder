# OpenBuilder

## English
OpenBuilder is a premium construction management platform with integrated documentation and AI-driven reporting.

### Architecture
This project is currently undergoing a phased expansion inspired by the Procore Developer Portal. It uses a modular PHP structure with a built-in Markdown documentation engine.

### Directory Structure
- `src/`: Core PHP logic and controllers.
- `public/`: Static assets (CSS, JS, images).
- `docs/`: Markdown-based documentation content.
- `layouts/`: Reusable HTML fragments.
- `docs/buildnotes/`: Detailed phase-by-phase implementation logs.

## Español
OpenBuilder es una plataforma de gestión de construcción de primera clase con documentación integrada e informes impulsados por IA.

### Arquitectura
Este proyecto está experimentando actualmente una expansión por fases inspirada en el Portal del Desarrollador de Procore. Utiliza una estructura PHP modular con un motor de documentación Markdown incorporado.

### Estructura de Directorios
- `src/`: Lógica central de PHP y controladores.
- `public/`: Activos estáticos (CSS, JS, imágenes).
- `docs/`: Contenido de documentación basado en Markdown.
- `layouts/`: Fragmentos HTML reutilizables.
- `docs/buildnotes/`: Registros detallados de implementación fase por fase.

## Setup / Configuración
1. Ensure you have PHP 8.x installed. / Asegúrese de tener instalado PHP 8.x.
2. Run `php -S localhost:8000` to start the development server. / Ejecute `php -S localhost:8000` para iniciar el servidor de desarrollo.
3. Access the dashboard at `http://localhost:8000`. / Acceda al panel de control en `http://localhost:8000`.
