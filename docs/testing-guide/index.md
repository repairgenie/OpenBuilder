# Testing Guide / Guía de Pruebas

## English
This guide outlines the standard testing procedures for OpenBuilder.

### Playwright Tests
- All features must have a corresponding Playwright script in `tests/playwright/`.
- Run tests using: `npx playwright test`.

## Español
Esta guía describe los procedimientos de prueba estándar para OpenBuilder.

### Pruebas de Playwright
- Todas las características deben tener un script de Playwright correspondiente en `tests/playwright/`.
- Ejecute las pruebas usando: `npx playwright test`.
