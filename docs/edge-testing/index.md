# Edge Testing Guide / Guía de Pruebas de Casos Límite

## English
This guide focuses on edge cases and stress testing for OpenBuilder.

### Scenarios
1. Rapid consecutive submissions.
2. Large data inputs in AI reports.
3. Network latency simulation.

2. Grandes entradas de datos en los informes de IA.
