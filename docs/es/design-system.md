# Sistema de Diseño

## Español
El sistema de diseño de OpenBuilder se basa en un conjunto de variables CSS (tokens) que garantizan la consistencia y una sensación de alta calidad.

### Paleta de Colores
- **Primario**: Base índigo para las acciones principales.
- **Éxito**: Verde esmeralda para las tareas completadas.
- **Advertencia**: Ámbar para las alertas.
- **Peligro**: Carmesí para los errores.

### Espaciado
Utiliza una escala consistente basada en rem (`--space-1` a `--space-10`).
