# Guía de Estructura de Directorios

OpenBuilder utiliza una estructura de directorios modular:
- `src/`: Lógica central e inicialización de la base de datos.
- `layouts/`: Fragmentos globales de la interfaz de usuario (encabezado, barra lateral, pie de página).
- `templates/`: Contenido específico de la página.
- `public/`: Activos estáticos.
- `docs/`: Documentación.
- `tests/`: Scripts de prueba.
