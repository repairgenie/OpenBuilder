# Informes y Exportaciones

## Español
OpenBuilder admite informes profesionales y generación de documentos físicos.
- **Optimización de Impresión**: Cada página está optimizada para la impresión utilizando reglas CSS dedicadas.
- **Diseño Limpio**: La navegación y los botones interactivos se eliminan automáticamente de la versión impresa.
- **Listo para las Partes Interesadas**: Las vistas de Diarios y Presupuesto están diseñadas para compartirse como PDF profesionales o documentos impresos.
