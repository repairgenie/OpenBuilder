# Guía de BIM (Español)

## Resumen
El módulo BIM proporciona un entorno 3D de alta fidelidad para la coordinación de proyectos, la detección de conflictos y el cómputo de cantidades.

## Características Clave
1. **Visor 3D**: Navegue por modelos arquitectónicos y estructurales con modos de órbita, desplazamiento y recorrido en primera persona.
2. **Detección de Conflictos**: Identifique automáticamente colisiones geométricas entre disciplinas (ej. HVAC vs. Estructura).
3. **Coordinación 2D/3D**: Vista simultánea de planos 2D y modelos 3D para verificación espacial.
4. **Problemas BIM**: Vincule objetos específicos del modelo a RFIs para una comunicación técnica clara.
5. **Cómputo del Modelo**: Extraiga cantidades (volumen, área, conteo) directamente de los metadatos del modelo.
6. **Vista VR/AR**: Visualización inmersiva en dispositivos móviles compatibles.

## Flujo de Trabajo
1. Cargue un modelo IFC o Revit.
2. Ejecute la Detección de Conflictos automatizada.
3. Revise los conflictos y cree RFIs vinculadas.
4. Use las herramientas de Cómputo para verificar las cantidades del presupuesto.
