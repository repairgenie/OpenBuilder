# Cómo Escribir Documentación

## Español
Para agregar nueva documentación, cree un archivo Markdown en `docs/en/` y su traducción en `docs/es/`.
Luego acceda a él a través de `?page=docs&doc=nombre-de-su-archivo`.

### Formato
- Utilice Markdown estándar.
- Los encabezados comienzan con `#`.
- Los enlaces utilizan `[texto](url)`.
