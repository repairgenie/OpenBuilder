# Guía del Administrador (Español)

## Administración del Sistema
OpenBuilder proporciona herramientas robustas para gestionar configuraciones de proyectos, permisos de usuario e integridad de datos.

## Gestión de Usuarios y RBAC
- **Control de Acceso Basado en Roles**: Asigne usuarios a roles específicos (Administrador, Gerente, Subcontratista).
- **Permisos**: Controle el acceso a datos financieros, ajustes del proyecto y capacidades de cierre de RFI.
- **Seguridad MFA**: Imponga la autenticación de múltiples factores para cuentas de alto nivel para proteger los datos sensibles del proyecto.

## Configuración del Proyecto
- **Marca**: Personalice el nombre y la ubicación del proyecto.
- **Ajustes de Notificación**: Configure alertas granulares para umbrales presupuestarios y actividad de RFI.
- **Apariencia**: Seleccione entre temas de color predefinidos para coincidir con la marca de la empresa.

## Cumplimiento y Seguridad
- **Registros de Auditoría**: Revise un historial completo de cambios administrativos, incluyendo el seguimiento de IP y marcas de tiempo.
- **Portabilidad de Datos**: Exporte conjuntos de datos completos del proyecto en formato JSON para auditorías externas o migración de sistemas.
- **Archivado de Proyectos**: Archive de forma segura los proyectos finalizados a un estado de solo lectura para preservar los datos históricos.

## Salud del Sistema
Monitoree la disponibilidad de los servicios principales (Base de datos, API de IA) a través del Panel de Salud integrado.
