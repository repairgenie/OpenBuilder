# Dynamic Navigation / Navegación Dinámica

## English
OpenBuilder's sidebar is driven by `src/navigation.json`. This allows for easy updates to the menu structure without modifying PHP code.
The system supports bilingual titles and active state tracking.

## Español
La barra lateral de OpenBuilder se controla mediante `src/navigation.json`. Esto permite actualizaciones fáciles de la estructura del menú sin modificar el código PHP.
El sistema admite títulos bilingües y seguimiento del estado activo.
