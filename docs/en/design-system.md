# Design System / Sistema de Diseño

## English
OpenBuilder's design system is built on a set of CSS variables (tokens) that ensure consistency and premium feel.

### Color Palette
- **Primary**: Indigo base for main actions.
- **Success**: Emerald green for completed tasks.
- **Warning**: Amber for alerts.
- **Danger**: Crimson for errors.

### Spacing
Uses a consistent rem-based scale (`--space-1` to `--space-10`).

## Español
El sistema de diseño de OpenBuilder se basa en un conjunto de variables CSS (tokens) que garantizan la consistencia y una sensación premium.

### Paleta de Colores
- **Primario**: Base índigo para acciones principales.
- **Éxito**: Verde esmeralda para tareas completadas.
- **Advertencia**: Ámbar para alertas.
- **Peligro**: Carmesí para errores.

### Espaciado
Utiliza una escala consistente basada en rem (`--space-1` a `--space-10`).
