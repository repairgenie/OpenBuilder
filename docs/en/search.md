# Search Functionality / Funcionalidad de Búsqueda

## English
OpenBuilder features a live search in the topbar. It uses a fuzzy search algorithm against `public/search.json`.
Results are language-aware, meaning if you are in the Spanish version, only Spanish documents will be shown.

## Español
OpenBuilder cuenta con una búsqueda en vivo en la barra superior. Utiliza un algoritmo de búsqueda difusa contra `public/search.json`.
Los resultados dependen del idioma, lo que significa que si estás en la versión en español, solo se mostrarán los documentos en español.
