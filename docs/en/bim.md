# BIM (Building Information Modeling) Guide (English)

## Overview
The BIM module provides a high-fidelity 3D environment for project coordination, clash detection, and quantity takeoffs.

## Key Features
1. **3D Viewer**: Navigate architectural and structural models with orbit, pan, and first-person walkthrough modes.
2. **Clash Detection**: Automatically identify geometric conflicts between disciplines (e.g., HVAC vs. Structure).
3. **2D/3D Coordination**: Simultaneous view of 2D plans and 3D models for spatial verification.
4. **BIM Issues**: Link specific model objects to RFIs for clear technical communication.
5. **Model Takeoff**: Extract quantities (volume, area, count) directly from model metadata.
6. **VR/AR Preview**: Immersive visualization on supported mobile devices.

## Workflow
1. Upload an IFC or Revit model.
2. Run automated Clash Detection.
3. Review conflicts and create linked RFIs.
4. Use Takeoff tools to verify budget quantities.
