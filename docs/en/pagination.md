# Pagination / Paginación

## English
OpenBuilder uses a unified pagination system to ensure high performance even with thousands of records.
- **Dynamic Calculation**: Automatic detection of total pages and current offset.
- **Reusable Component**: Shared between RFIs, Daily Logs, and other modules.
- **SEO Friendly**: Uses query parameters (`?p=2`) for easy navigation and bookmarking.

## Español
OpenBuilder utiliza un sistema de paginación unificado para garantizar un alto rendimiento incluso con miles de registros.
- **Cálculo Dinámico**: Detección automática de páginas totales y compensación actual.
- **Componente Reutilizable**: Compartido entre RFI, Diarios y otros módulos.
- **Amigable con SEO**: Utiliza parámetros de consulta (`?p=2`) para facilitar la navegación y los marcadores.
