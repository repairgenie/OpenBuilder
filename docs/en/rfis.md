# RFI Management / Gestión de RFI

## English
The RFI module provides a centralized location for tracking project questions and answers.
- **Status Badges**: Visual indicators for Open and Closed RFIs.
- **Priority Tracking**: Color-coded priority levels (High, Medium, Low).
- **Responsive Table**: Optimized for both desktop and mobile views.

## Español
El módulo RFI proporciona una ubicación centralizada para rastrear preguntas y respuestas del proyecto.
- **Insignias de Estado**: Indicadores visuales para RFI abiertas y cerradas.
- **Seguimiento de Prioridad**: Niveles de prioridad codificados por colores (Alta, Media, Baja).
- **Tabla Responsiva**: Optimizada para vistas de escritorio y móviles.
