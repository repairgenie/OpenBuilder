# Drawings & Documentation Guide (English)

## Overview
The Drawings module is the central repository for all project blueprints, ensuring that field teams always work from the latest revision.

## Key Features
1. **High-Res Viewer**: View ultra-high-resolution architectural and engineering plans on any device.
2. **Automatic OCR**: Sheets are automatically named and numbered during upload using optical character recognition.
3. **Discipline Filtering**: Quickly filter drawings by Architectural, Structural, MEP, and more.
4. **Spatial Hyperlinking**: Automatic detection of RFI and Submittal references with direct click-through.
5. **Mobile Markups**: Add clouds, shapes, and comments in the field (Private or Public).
6. **Side-by-Side Comparison**: Overlay two versions of a drawing with color-coded (Red/Green) change detection.
7. **GPS Navigation**: Automatically find the drawing for your current location on-site.
8. **Export with Markups**: Generate PDF copies of drawings with all field markups burned-in.

## Workflow
1. Upload new drawing sets.
2. Review OCR results and publish to the field.
3. Use Markup tools to document site conditions.
4. Compare revisions to identify owner-directed or design-driven changes.
