# Notifications / Notificaciones

## English
The Notification system keeps you informed of critical project events.
- **Visual Alerts**: A pulsing badge indicates new notifications.
- **Quick Actions**: Access important updates directly from the topbar.
- **Bilingual Alerts**: All system notifications are automatically translated.

## Español
El sistema de Notificaciones lo mantiene informado sobre eventos críticos del proyecto.
- **Alertas Visuales**: Una insignia pulsante indica nuevas notificaciones.
- **Acciones Rápidas**: Acceda a actualizaciones importantes directamente desde la barra superior.
- **Alertas Bilingües**: Todas las notificaciones del sistema se traducen automáticamente.
