# Mobile Responsiveness / Responsividad Móvil

## English
OpenBuilder is designed to be fully responsive.
- **Hamburger Menu**: On mobile devices, the sidebar is hidden by default and can be toggled using the hamburger icon in the topbar.
- **Overlay**: Clicking outside the sidebar on mobile will automatically close it.
- **Touch Targets**: All interactive elements are sized for touch interaction.

## Español
OpenBuilder está diseñado para ser completamente responsivo.
- **Menú de Hamburguesa**: En dispositivos móviles, la barra lateral está oculta por defecto y se puede alternar con el icono de hamburguesa en la barra superior.
- **Superposición**: Al hacer clic fuera de la barra lateral en el móvil, se cerrará automáticamente.
- **Objetivos Táctiles**: Todos los elementos interactivos están dimensionados para la interacción táctil.
