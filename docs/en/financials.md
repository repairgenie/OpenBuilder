# Project Financials Guide (English)

## Overview
The Financials module provides a robust framework for managing project commitments, costs, and cash flow.

## Key Features
1. **Commitments**: Formalize agreements with subcontractors through Subcontracts and Purchase Orders.
2. **Schedule of Values (SOV)**: Break down contract values into detailed line items for precise billing.
3. **Progress Claims**: Manage monthly subcontractor invoicing with automated retention (holdback) calculations.
4. **Direct Costs**: Track miscellaneous site expenses, material purchases, and internal costs.
5. **Change Integration**: Automatically update commitment values upon approval of Change Orders.
6. **Cash Flow Visualization**: Real-time charts comparing projected income against actual expenses.
7. **Funding Sources**: Manage construction loans, grants, and owner equity draws.
8. **AI Anomaly Detection**: Automated auditing of transactions to identify errors or potential fraud.

## Workflow
1. Award a Bid and convert it into a Commitment (Subcontract/PO).
2. Establish the Schedule of Values for the commitment.
3. Subcontractors submit monthly Progress Claims based on work completed.
4. Review and approve claims, with retention automatically withheld.
5. Monitor project liquidity through the Cash Flow dashboard.
