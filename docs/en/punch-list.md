# Punch List & Closeout Guide (English)

## Overview
The Punch List module manages the final stages of a project, ensuring all deficiencies are corrected and all documentation is gathered for handover.

## Key Features
1. **Rapid Capture**: High-speed field entry for site deficiencies with location tagging.
2. **Multi-step Approval**: Track items through "Work Required", "Ready for Review", and "Verified" statuses.
3. **Batch Assignment**: Delegate multiple items to subcontractors in a single action.
4. **Mobile Walkthrough**: Optimized field mode for accepting or rejecting corrected work.
5. **AI Classification**: Automatically categorize punch items by trade and priority.
6. **Closeout Documents**: Track warranties, manuals, and as-built submittals from vendors.
7. **As-built Generation**: Compile marked-up drawings into a final project package.
8. **Final Project Report**: Automated summary of quality and financial performance.

## Workflow
1. Perform a final site walkthrough and log punch items.
2. Assign items to subcontractors for correction.
3. Subcontractors mark items as "Ready for Review".
4. Inspector verifies the work and marks as "Verified".
5. Collect all Closeout Documentation and generate the Final Report.
