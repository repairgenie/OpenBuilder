# Bidding & Procurement Guide (English)

## Overview
The Bidding module manages the subcontractor selection process, from invitation to contract award.

## Key Features
1. **Bid Packages**: Group scopes of work for targeted bidding.
2. **Vendor Portal**: Secure interface for subcontractors to submit pricing and exclusions.
3. **Comparison Tools**: Side-by-side analysis of bids with "Lowest Bid" highlighting.
4. **AI Analysis**: Automated anomaly detection and vendor recommendations.
5. **Pre-qualification**: Collect safety (EMR) and financial (Bonding) data from vendors.

## Workflow
1. Create a Bid Package.
2. Invite Vendors from the Directory.
3. Review submitted Bids using the Comparison tool.
4. Award the contract to the best-value vendor.
