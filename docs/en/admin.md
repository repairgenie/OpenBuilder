# Administrator Guide (English)

## System Administration
OpenBuilder provides robust tools for managing project configurations, user permissions, and data integrity.

## User Management & RBAC
- **Role-Based Access Control**: Assign users to specific roles (Admin, Manager, Subcontractor).
- **Permissions**: Control access to financial data, project settings, and RFI closure capabilities.
- **MFA Security**: Enforce multi-factor authentication for high-level accounts to protect sensitive project data.

## Project Configuration
- **Branding**: Customize project name and location.
- **Notification Settings**: Configure granular alerts for budget thresholds and RFI activity.
- **Appearance**: Select from predefined color themes to match company branding.

## Compliance & Security
- **Audit Logs**: Review a complete history of administrative changes, including IP tracking and timestamps.
- **Data Portability**: Export full project datasets in JSON format for external auditing or system migration.
- **Project Archival**: Securely archive completed projects to a read-only state to preserve historical data.

## System Health
Monitor core service availability (Database, AI API) through the integrated Health Dashboard.
