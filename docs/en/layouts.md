# Layout & Components / Diseño y Componentes

## English
OpenBuilder's UI is divided into modular fragments for better maintainability:
- `header.php`: Document head and opening tags.
- `sidebar.php`: Main navigation menu.
- `topbar.php`: Search bar and user profile.
- `footer.php`: Copyright info and closing tags.

## Español
La interfaz de usuario de OpenBuilder se divide en fragmentos modulares para un mejor mantenimiento:
- `header.php`: Encabezado del documento y etiquetas de apertura.
- `sidebar.php`: Menú de navegación principal.
- `topbar.php`: Barra de búsqueda y perfil de usuario.
- `footer.php`: Información de derechos de autor y etiquetas de cierre.
